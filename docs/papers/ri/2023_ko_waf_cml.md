# Ko et al. 2023 — Consensus ML (CML) for RI with HWRF predictors

**Citation**
- Ko, K. K., J. Kaplan, M. DeMaria, E. N. Lonfat, R. Rogers, and C. R. Sampson (2023).
  *Development of a Consensus Machine Learning Model for Hurricane Rapid Intensification Forecasts with HWRF Data*.
  Weather and Forecasting. DOI: 10.1175/WAF-D-22-0217.1

**What it is**
- Consensus ML (CML) RI forecasts using predictors from high‑resolution HWRF output.

**Key points (from repository description)**
- Compares multiple ML models vs SHIPS‑RII and official guidance.
- Reports probability of detection (POD) and false alarm rate (FAR) improvements.

**Why we care**
- Provides a modern, operationally‑relevant ML baseline for RI probability.
